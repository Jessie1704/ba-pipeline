# UX Heuristics Check

Run per screen in `/ba-ux`. Record only findings (✘) with an action.

| # | Heuristic | Check |
|---|-----------|-------|
| 1 | Visibility of status | User always knows what's happening (loading, saved, submitted, step 2 of 4)? |
| 2 | Match the real world | Labels use the business's words (glossary), not system jargon? |
| 3 | Control & freedom | Cancel, back, undo available? Unsaved-changes warning? |
| 4 | Consistency | Same action = same label/position across screens; follows design system? |
| 5 | Error prevention | Constraints shown before input (formats, limits); destructive actions confirmed? |
| 6 | Recognition over recall | Options visible; previous entries kept; no need to remember data between screens? |
| 7 | Efficiency | Shortest path for frequent tasks; sensible defaults; bulk actions where volume is high? |
| 8 | Minimal design | Only what this role needs for this task; priority content first? |
| 9 | Error recovery | Error says what happened, why, and how to fix it — next to the field? |
| 10 | Help | Helper text where rules aren't obvious; link to support? |
| 11 | Accessibility | Labels, focus order, keyboard-only path, contrast, not colour-only, touch targets ≥ 24 px? |
| 12 | Responsive | Works at the minimum width; no horizontal scroll; key action reachable? |
